# 实验、运行与制品协议

## 冻结实验计划

进入 `protocol_locked` 前记录不可变 `plan_id`、研究问题与假设版本、主要/次要指标、数据 manifest 与许可、环境锁文件哈希、参数数组、随机种子、硬件、资源预算、预定分析、停止条件、失败判定、允许重试和偏离处理。

实验必须基于干净的 `basis_commit`。计划文件不得嵌入其所在提交的哈希；CLI 在启动时把包含该计划的实际干净 `HEAD` 记录为 `basis_commit`，并独立校验协议、脚本、输入和计划 SHA-256。若工作树脏、依赖 Gate 失效、输入哈希不符或预算字段缺失，禁止启动。修改计划时创建新版本并使依赖运行和审批过期。

## 执行运行

- 使用 `aiscience run execute <project_id> <plan_id>`；命令以参数数组传入，不使用 shell 字符串拼接。
- 获取项目/运行锁，为每次尝试分配唯一 `run_id`，输出只写 `runs/<run_id>/`。
- 保存开始/结束 UTC 时间、提交、环境、命令、种子、硬件、stdout/stderr、指标、制品、偏离、重试、父运行和终止原因。
- 在 Windows 上用 Job Object 管理完整进程树并执行超时；失败时终止并等待子进程，记录无法保证的逃逸风险。
- 网络、GPU、内存、时间和文件边界分别记录为 `hard`、`best_effort` 或 `observed_only`。观察到资源使用不等于隔离得到保证。

缺少输入使用 `input_unavailable`，不计作实验失败。预期内的阴性结果和真实失败都保留；禁止删除失败运行后重用其 ID。

## 事务与恢复

对象写入与事件追加属于同一逻辑事务。写入顺序为：取得独占锁、写事务意图 journal、写同目录临时文件、刷新文件与父目录、原子替换、追加带长度和哈希的 event frame、提交 journal。启动时验证帧长度、哈希链和对象锚点；隔离损坏尾记录并恢复到最后有效节点，不静默修补历史。

event 保存对象相对路径、版本、SHA-256、依赖边和前一事件哈希。孤立对象、绝对路径、哈希错误或依赖缺失均无效。

## 制品与本地 CAS

超过 10 MiB、敏感或不可再分发文件放入 gitignored `.aiscience-data/` 内容寻址存储。Git 仅跟踪 manifest、许可、获取/挂载说明、预期哈希和复现状态。检查路径解析后的目标仍位于项目或 CAS 边界内；禁止通过 `..`、符号链接或 junction 越界写入。

## 复现等级

- `full`：许可允许的输入、锁定环境和步骤足以在干净 checkout 独立复现。
- `local_only`：本机受控输入可复现，但无法合法打包全部输入。
- `partial`：仅部分结果可重建，明确列出缺口。
- `unavailable`：关键输入或能力不可用。

不要承诺全新机器在无缓存条件下离线安装依赖。确定性 JSON/CSV 可比较 SHA-256；浮点、图像和 PDF 必须使用预先声明的容差或结构/渲染检查。
