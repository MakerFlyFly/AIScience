# 分析、写作、审核与交付协议

## 统计分析

优先执行冻结协议中的主要分析，再进行标明探索性的稳健性、敏感性或亚组分析。记录样本排除、缺失值、多重比较、效应量、不确定性、模型诊断、随机性和所有协议偏离。禁止在看到结果后静默改主要指标、停止规则或检验族。

每个表、图和数字绑定生成运行、脚本/参数、输入哈希和制品哈希。无法重建或与台账冲突的结果不得进入论文。

## 双语论文

英文权威稿固定为 `paper/en/manuscript.md`，中文阅读稿固定为 `paper/zh/manuscript.md`；两者共用 `paper/references.bib`、图表和 `paper/citation-map.json`。

先更新英文稿和 claim ledger，再翻译中文稿。citation map 记录段落/锚点、claim 版本、来源或运行、英文文本哈希与中文同步状态。检查数字、引文键、图表锚点和 claim 覆盖；英文变化立即使对应中文内容 stale。语义等价由双语编辑和审计员检查，冲突以英文为准，但修复前禁止 G2。

每次 LLM 生成/改写追加事件：角色、脱敏输入摘要、指令配置及提交、来源/run 引用、工具轨迹、输出哈希，以及各字段的 `observed`、`declared` 或 `unknown`。统一标为 `traceable_only/non_deterministic`。

使用 Pandoc + XeLaTeX 构建中英文 PDF 并保存构建日志。缺少工具时返回环境能力错误，不用未审计的替代稿冒充最终 PDF。

## 审核

审核依次覆盖：

1. 证据：错误引用、撤稿/勘误、仅摘要证据、孤立或过度主张。
2. 统计：泄漏、p-hacking、多重比较、样本排除、模型假设、图文与台账冲突。
3. 论文：英文/中文语义、数字、引文、图表、局限、作者和 AI 披露。
4. 复现：干净 checkout、锁定环境、输入许可、运行命令、容差和 manifest。
5. 安全：秘密、PII、绝对路径、受限全文/数据和 demo Gate 污染。

发现按高/中/低风险记录，包含证据、影响、最早受影响阶段和处置。高/中风险必须修复或由人类明确接受；任何回退都会使依赖批准和交付候选过期。

## 交付

`package prepare` 创建候选 manifest，列出论文源与 PDF、数据/代码 manifest、运行和环境、复现说明、局限、许可、审核、AI 披露及所有 SHA-256。候选包必须通过秘密/PII、绝对路径、许可、完整性、双语同步和 Gate 校验。

G2 绑定候选 manifest 与依赖闭包。批准后任何字节变化均需重新准备和审批。`package finalize` 只允许从 `delivery_ready` 的已批准候选生成最终包；它写入 `delivered` 事实、创建本地完成提交，并在该提交上创建 annotated Git tag。公共 CLI 不允许跳过 tag，也不得把含自身提交哈希的文件写回同一提交。最终化前必须运行 `uv run --python 3.12 aiscience repo-scan`，扫描 Git 已跟踪及暂存的项目文本。
